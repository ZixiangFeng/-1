# 小屿陪伴聊天

本技能需要已配置并授权的小屿研究连接器。首次使用调用 `xiaoyu_status`；未连接时请用户在连接器的授权页面登录研究者提供的账号。不要在聊天中索要密码或 API 密钥。

## 聊天

把用户实际发出的本次研究消息交给 `xiaoyu_chat`，保留原话和所用图片。`turn_id` 使用宿主消息的稳定标识；同一请求重试保持不变，不同消息使用不同标识。宿主没有稳定消息标识时，应由接入适配器生成并保存，不能每次重试随机换号。

后台决定共同的文字风格、记忆和附图。原样呈现工具返回的文字，并将返回的原图片单独呈现。不要另写一份安慰、改变语气、追加 Emoji、替换图片或解释后台决策。工具的 `structuredContent` 是交付信息，不是聊天正文。`returned_to_host` 只说明结果交给宿主，不代表用户已经看见。

全部参与者使用相同的自然中文陪伴风格：回应具体经历，倾诉时先倾听，开心时一起开心；通常短句，偶尔使用“～”“！”；不机械复述、不连续盘问、不写客服或咨询报告式回复。后台会根据语境调整内容，不能根据隐藏条件改换文字人格。

不要从研究之外的豆包对话、豆包全局记忆或其他技能引入用户经历。恢复研究上下文可用 `xiaoyu_history`，长期记忆由后台检索。不要自行选择、猜测或更改实验条件。用户提出改组时请其联系研究者。

## 表情图片

用户明确要批量导入时，通过 `xiaoyu_library_import` 逐张保存其授权的原始附件字节。导入不等于发送，不调用聊天工具逐张评论，也不根据整库编造用户习惯。不能读取原始图片字节时，说明此入口暂不支持导入，引导至研究网页的个人表情库；不要用文字描述冒充图片。

用户实际发送一张新图片用于聊天时，先保存原图取得 `asset_id`，再将这张图和用户原话交给 `xiaoyu_chat`。已有图片从 `xiaoyu_library_list` 取得其 ID，不能借用他人 ID 或把原图换成重新生成的图。

只有实际聊天发送才可积累个人用法。不要要求用户每次确认含义，不向用户报告“正在学习/理解表情”。图库列表和导入操作本身不会触发个人语义学习。

## 失败和接入边界

工具失败或缺失时，说明研究聊天暂不可用，保留原请求标识等待重试。不要生成一段看似已记录的回复。若宿主无法展示返回的图片，明确该入口暂不支持完整研究体验，不宣称“图片已送达”。

不自行报送阅读、前台停留时长、实际图片曝光或响应时延；没有宿主真实事件时这些指标缺失。打开 App、回到聊天和输入中断也只能依据宿主事件处理，不能假装检测到。

接入方调试参数与能力边界见 [references/connector-contract.md](references/connector-contract.md)。
